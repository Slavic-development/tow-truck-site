# Качественный эвакуатор

Адаптивный одностраничный сайт на HTML, CSS и JavaScript с Vite. Node.js 22.12+ или 24.

```sh
npm ci
npm run dev
```

Проверка сборки: `npm run build`. Просмотр сборки: `npm run preview`.

Номер WhatsApp задаётся в `js/main.js` в массиве `contacts` (два номера): международный формат, только цифры. Пока номера пустые, кнопка показывает сообщение и не открывает переписку с вымышленным номером.

Город, цены и фотографии необходимо уточнить перед публикацией. График: круглосуточно; доступна междугородняя и сложная эвакуация. Присланные в чат фотографии пока отсутствуют среди файлов рабочей среды. Иллюстрация на первом экране нарисована в SVG, это не фотография выполненной работы.

Структура: `index.html` — тексты, `css/style.css` — оформление, `js/main.js` — контакты и кнопки, `images/` — фотографии. В объекте контакта `number` — номер с кодом страны, только цифры; `display` — удобное отображение; `whatsapp` — наличие WhatsApp. Номера можно выделить мышью или скопировать кнопкой.
